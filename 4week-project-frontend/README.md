# 4-Week Project Frontend

This repository contains the frontend for my Cold Chain Operations Portal project completed during my internship at Encon Pharma. It was built using Next.js, TypeScript, Tailwind CSS and TanStack Query.

The frontend allows users to create, edit, delete and view cold-chain temperature readings through a clear web interface. It connects to the real deployed backend using a Next.js API proxy and is hosted publicly using AWS Amplify.
